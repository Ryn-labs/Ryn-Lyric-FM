# Ryn Lyric FM

**Created by Ryn.** Synced, fully customisable lyrics for your OBS stream, from Spotify, YouTube, SoundCloud and more.

## Download

Get the latest installer from the [Releases page](https://github.com/Ryn-labs/Ryn-Lyric-FM/releases/latest), then run the `.msi`.

Windows may show "Windows protected your PC" because the installer isn't code-signed. Click **More info → Run anyway**.

## Updating

Ryn Lyric FM checks this page for new versions. When an update is out, open the app and press **Update**.
